## 今回やること
- **機能名**：複数文書比較表示（2〜3ペイン切替）
- **今回の目標（スプリントゴール）への寄与**：異なる複数（2つまたは3つ）の文書・添付文書を並べて表示し、突き合わせながら確認できるようにする

## 仕様（AIが迷わないように具体的に）
| 項目 | 内容 |
|---|---|
| 対象ファイル | `frontend/src/features/compare/CompareViewer.tsx`、`frontend/src/pages/DocumentReviewPage.tsx` |
| 対象の関数・IF | `<CompareViewer panes={paneNodes} activeIndex={activePaneIndex} onSelectPane={...} />` が `DocumentViewer` を `panes.length`（2または3）個横並びで表示する。`DocumentReviewPage` は「文書比較モード」トグルと、比較モードON時のみ表示される「2枚比較／3枚比較」の切替ボタンを持つ。ツリーで選んだ文書は、現在アクティブなペイン（クリックした順に自動的に次のペインへ進む。ペインのヘッダーをクリックすれば明示的に対象ペインを切り替えられる）に入る。各ペインは独立してページ送り・拡大縮小が可能。ペイン数を2→3や3→2に切り替えても、既存の割り当ては可能な範囲で保持される（3→2の場合は3番目の選択が失われる） |
| 対象外（やらないこと） | 4枚以上の同時表示、左右（各ペイン間）のスクロール同期・ページ同期（独立動作でよいとユーザー確認済み）、差分のハイライト表示 |
| 動作確認手順（できたの基準） | ①比較モードON→ツリーで1つ目を選ぶとペイン1に表示される／②2つ目を選ぶとペイン2に表示される（2枚比較の場合はここでペイン1に戻る）／③「3枚比較」に切り替えるとペイン3が現れ、3つ目の文書を選ぶとそこに表示される／④未選択のペインでは「文書を選択してください」の空状態が表示される／⑤各ペイン独立にページ送り・拡大縮小ができる／⑥「ツリーを隠す」でサイドバーを折りたたみ、ペインの表示幅が広がることを確認／⑦比較モードOFFに戻すと単票表示に戻る |
