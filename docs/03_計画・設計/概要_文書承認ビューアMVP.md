> **2026-08-29 追記（プロトタイプ確認4回目のフィードバック反映）**：①タブレット対応の方針を修正——「不要」から「**最低限は対応する**」に変更し、タブレット幅では文書ツリーの既定幅を狭め、さらにドラッグで幅調整できるようにしてPDF表示幅を確保した（下記P8）。②メタ情報の画面表示名を「**伝票情報**」に変更（内部のコード上の名称は変更なし）。

## 今回やること

- **プロダクト名（仮）**：documentview（文書承認ビューア）
- **今回の目標（今回のミッション）**：フロントエンドのみの対話式プロトタイプで、文書ツリー表示・PDF/画像プレビュー・複数文書比較（2〜3ペイン）の**画面イメージと動作イメージを固める**。モックデータを使用し、認証・既存システム連携は対象外
- **狙い**：紙で確認・押印していた事務をブラウザだけで完結できるようにする（電子化）の第一歩として、まず「見る」体験を触って確認できる形にする。UXが固まってから、既存システム（基盤システム・Azure AD）との連携を後続フェーズで検討する

## システム構成（今回のプロトタイプ）

```
documentview/
  frontend/                         # React + TypeScript（Vite）
    public/
      mock-files/                   # サンプルPDF・画像
    src/
      types/          document.ts        # DocumentTreeNode・MetaField 等の共有型（将来の実APIレスポンス型と合わせる）
      utils/          file.ts, metaField.ts   # 拡張子・ファイル名抽出／メタ情報の整形・カウント・絞り込み
      mocks/          documentTree.ts
      features/
        tree/          DocumentTree.tsx, DocumentTreeNode.tsx, useDocumentTree.ts
        viewer/        DocumentViewer.tsx, PdfViewer.tsx, ImageViewer.tsx, UnsupportedFileViewer.tsx
        compare/       CompareViewer.tsx
        meta/          MetadataPanel.tsx, MetaFieldGroup.tsx, MetaFieldTable.tsx
      pages/           DocumentReviewPage.tsx  # サイドバー幅の自動調整・ドラッグリサイズもここで管理
      App.tsx
```

- PDF表示は `pdfjs-dist`（`react-pdf`）、画像表示は `<img>` を使用。
- データ取得層（`useDocumentTree` 等）はモックを返す形にしておき、次フェーズで実APIに差し替えるだけで済むようインターフェースを合わせておく。
- バックエンド（Spring Boot）・Azure AD・共有フォルダ連携は今回のプロトタイプには含めない。

## 不確実性（まだ確定していないこと）

| 種類 | 内容 | いつ・どう確かめる |
|---|---|---|
| 曖昧性 | 2文書比較の「左右への割り当て方法」（クリック順／ドラッグ／ボタン）が未確定 | プロトタイプで複数パターンを試し、ユーザーに触ってもらって決める |
| 曖昧性 | 実際の文書名・添付構成の典型パターンをモックにどこまで反映すべきか未確認 | プロトタイプを見せながら「実際の構成に近いか」を確認・調整 |
| 曖昧性 | プレビュー非対応と判定する形式の範囲（Excel/Wordのみか等）が未確認 | 次フェーズで基盤システム担当に実際の添付ファイル形式一覧をヒアリング（[ファイルダウンロード機能.md](ファイルダウンロード機能.md)） |
| 変動性 | 添付文書の階層が実データで何段まであり得るか未確認（今回は多段ケースをモックで用意して見た目だけ確認） | 次フェーズ（既存システム連携）で実データを確認 |
| 曖昧性 | 実際のメタ情報の項目名・階層構造・明細の形が、モックで想定した「ラベル＋値／1件だけのグループ／繰り返し行の表」で表現しきれるか未確認 | 次フェーズで基盤システム担当にメタ情報のスキーマ・サンプルデータをヒアリング（[文書メタ情報表示.md](文書メタ情報表示.md)） |

**解消済み**：比較表示時の左右ページ送り同期は不要と確認（独立動作のままでよい）。3文書同時並び表示は「2〜3ペイン切替式＋ツリー折りたたみ」で実装し確認済み（[2文書比較表示（分割ビュー）.md](2文書比較表示（分割ビュー）.md)）。
